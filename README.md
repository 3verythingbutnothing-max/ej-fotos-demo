# EJFoto public project demo

[Open the demo](https://3verythingbutnothing-max.github.io/ej-fotos-demo/)

This repository contains only compiled website assets and licensed stock-photo fixtures. It is a technical project demonstration, not a live photography store. All sample media are public. Cart selections and simulated receipts stay in the visitor's browser. No uploads, event passwords, payments, supplier orders or customer details are collected.

The workflow source remains in its separate private repository. This artifact was built from source commit 2f75844856e76c59f3d492ed33774146ca1ce2c0. Update it from that source using npm run publish:pages.

Photo provenance and licenses are in demo/provenance.json and demo/PHOTO_LICENSE.md. Font license notices are in demo/font-licenses/.
